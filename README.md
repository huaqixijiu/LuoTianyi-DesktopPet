# 洛天依桌宠

一个面向 Windows 的洛天依 Q 版桌面宠物项目。现有桌宠、动画、音乐、通知、日历、文件回收站和设置功能已经实现；当前进入结构重构阶段，目标是在不改变用户可见行为的前提下整理工程边界。

计划功能包括透明桌宠窗口、待机与鼠标区域互动、网易云音乐全局快捷键控制、音乐播放状态检测、QQ/微信简要提醒，以及可配置的应用启动反应。

## 已确认的场景

- 网易云音乐：上一首、下一首、播放和暂停使用网易云全局快捷键，不接入网易云接口；命令结果由公开音频状态与曲名变化确认。
- 音乐动画：总开关可完全停用；智能模式让普通歌曲使用“享受音乐”、洛天依本人或合唱歌曲随机使用“音乐摇摆/一键唱歌”，也可固定任一动画供所有歌曲唯一使用。
- 音量：设置页与桌宠悬浮控制岛最右侧均提供“网易云音乐独立音量”；控制岛点击天依蓝扬声器后向上展开竖向滑杆，只调整 `cloudmusic.exe` 在 Windows 11 应用音量合成器中的公开音频会话，不读取或修改系统主音量及其它应用。
- 待机模式：双击按“华裳长发版 → 晶蓝礼服版 → 经典猫耳版”循环切换，当前外观会保存；设置中可关闭循环并固定当前外观。仅经典猫耳版连续 3 分钟无输入时显示“嘿嘿”、30 分钟进入“眠了呼吸”；晶蓝礼服版 30 分钟后随机进入可点击唤醒的睡觉或鸭子坐。
- 外观联动：华裳长发版、晶蓝礼服版自动使用“甜笑寻包版”，经典猫耳版自动使用“元气追包版”；设置只保留吃包子总开关，不再单独选择动画版本。Windows 右下角托盘菜单提供 50%～200% 桌宠显示大小滑杆。
- 原神启动：播放“你不许玩”三次并短暂置顶，结束后恢复用户原有的置顶选择。
- 原神后台彩蛋：原神进程仍在运行但不位于前台时，大约每小时在安全随机位置播放一次“心律共鸣·拜托”，播放后回到原位置。
- QQ/微信提醒：只显示来源应用和系统明确提供的标题，不读取消息正文；“代号洛天依·好奇摇摆”当前持续显示 30 秒，可被打开来源应用、全屏/锁屏、拖拽或更高优先级动作提前打断。
- 时间问候：早晨使用“早安浮动”，中午使用“干饭弹跳”，下午使用“十周年·摸鱼漂浮”，夜间使用“眠了呼吸”。
- 鼠标互动：支持头部、手部、身体等区域点击，以及拖拽和落地回弹；滚轮当前不绑定音量功能。
- 文件互动：把桌面文件拖近桌宠时播放“给我”，松手到角色身上后通过 Windows 原生接口移入回收站。

## 安全原则

项目不向游戏或聊天软件注入 DLL，不读取进程内存，不安装驱动，不挂钩游戏渲染，不抓取聊天数据库或网络流量。检测原神仅使用 Windows 提供的进程生命周期事件；受保护游戏位于前台时，停止模拟键盘输入和强制覆盖。

## 目录

```text
洛天依桌宠/
├─ src/                WPF 应用、核心逻辑、动画和 Windows 平台适配
├─ tests/              自动化测试
├─ tools/              资产编译等开发工具
├─ config/             可编辑的场景规则与默认设置
├─ docs/               需求、安全约束和动画映射
├─ assets/             运行时素材与正式加工产物
├─ 原素材/             本地原始素材与构建输入，不进 Git、不进发布包
├─ 候选素材_官方/      未筛选候选素材，完成确认后由用户手动删除
├─ .gitattributes      Git LFS 资源类型
└─ .gitignore          构建产物和本地临时文件忽略规则
```

构建输入已复制到根目录 `原素材/` 并完成路径切换；`assets/` 只保留运行时资源和正式加工产物。

## 开发与验证

需要 .NET 10 SDK 10.0.400 作为构建工具，以及 .NET Framework 4.8 Developer Pack 进行 net48 编译。项目正式目标仅为 `net48`，最终发布不携带 .NET 10 运行时。仓库使用 `global.json` 固定 SDK：

```powershell
dotnet restore LuoTianyiPet.sln
dotnet build LuoTianyiPet.sln --configuration Release
dotnet test LuoTianyiPet.sln --configuration Release --no-build
dotnet run --project src/LuoTianyiPet.App/LuoTianyiPet.App.csproj --configuration Release
```

发布脚本位于 `tools/packaging/`，便携包、MSIX 和旁加载包均固定使用 net48 x64；详见 [`packaging/README.md`](packaging/README.md)。

## 资源管理

图片、动画、模型和压缩包使用 Git LFS 管理。克隆本项目时需要安装 Git LFS，并运行：

```powershell
git lfs install
git lfs pull
```
