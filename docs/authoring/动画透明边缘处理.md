# 动画透明边缘处理

## 2026-09-14：根据实际截图进行第二轮白色颗粒修正

用户复核上一轮结果后指出，头发、裙摆和鞋边仍有连续的白色颗粒。复盘确认上一轮 `dark-contour-white-matte-wide` 虽然扩大了边缘范围，但仍沿用了“遇到完全不透明纯白就跳过”的保护条件；因此只清理了透明像素隐藏 RGB 和部分 Alpha，没有真正去掉箭头位置的纯白底色。

本轮仅调整该 profile：在已确认的深色轮廓白底素材中，允许对轮廓外侧的纯白不透明像素执行白底重合成；`coverage`、`coverage-white-matte` 和其他素材仍保留白色衣服、文字、贴纸描边和高光保护。新增回归测试验证纯白颗粒会降为可见但非不透明的边缘像素。

重新生成并复核 `alarm-tenth-birthday-coming` 与 `startup-afternoon-hurry`。全量筛查中两者最坏帧的白底筛查值分别由 9 降至 1、由 21 降至 3；net48 应用内 70 套动画 × 3 档缩放 × 2 种背景共 420 项检查全部通过。用户此前修改中的音乐悬浮岛和快捷面板规格文档未被覆盖。

## 范围与处理

扫描 69 套运行时动画、3375 个逻辑帧，实际解码 3373 帧（两套进食 WebP 各合并了一对重复帧）；深浅背景查看全部动画的筛查代表帧，另外查看实际 WPF 中间帧。筛查分数只用于定位，不把白色描边得分当成缺陷数量。

`config/animation-sources.json` 的 30 套素材显式设置 `edgeCleanup`，共处理 373 个源帧。仅允许已核对的二值 Alpha 来源；已有半透明的全身动作、睡眠光效及摸鱼无损 RGBA 不重复处理。

- `coverage`：透明交界内侧一像素按 sigma 0.45 生成覆盖率；不向透明区扩散、不删除任何非零 Alpha 像素，RGB 不变。用于元旦演唱、十二周年表情等自带白色贴纸描边的素材。
- `coverage-white-matte`：上述处理加保守的灰边还原；只检查中性灰、相邻深色轮廓、且附近没有白色笔画的像素。颜色拟合误差最多 8；保留白色／米白色文字外描边。用于心律共鸣组。
- `dark-contour-white-matte`：仅用于已经目视确认的“来不及了”黑线外侧白底残留，包含纯白颗粒；旁边必须有深色轮廓。白底重合成误差最多 1/255，人物内部仍逐字节不变。

处理发生在编译器缩放之前，缩放继续使用预乘 Alpha。选中素材的动态 WebP 使用无损编码，并关闭旧的放大锐化，避免再引入色边。所有处理参数在配置和 `animation_edge_cleanup.py` 中固定；官方源文件与 sourceSha256 不变。
