## 1. 项目目标

制作一个仅在 Windows 本地运行的洛天依 Q 版桌宠，包含透明桌面窗口、两种待机显示模式、动画状态机、鼠标身体区域互动、网易云音乐快捷键控制与播放检测、QQ/微信来源提醒、原神低权限联动，以及把用户主动拖入的文件移入 Windows 回收站。

## 2. 已接管的默认技术决策

- C# + WPF；源码默认以 .NET 10 构建，安装版默认发布为 .NET Framework 4.8；
- 完整安装版支持 Windows 10 22H2（19045）及 Windows 11；
- 普通用户权限运行，不以管理员身份启动；
- 默认提供不拆分动画资源、无需另装运行时的完整 MSIX；保留 .NET 10 自包含构建作为兼容回退；
- 状态机与 Windows 平台能力分层；
- GIF、动态 WebP、SVGA 和程序动效在构建阶段转换为统一运行时动画描述；
- 原始素材始终保留，派生资产写入 `assets/`；
- 配置采用带版本号的 JSON，并支持将旧配置迁移到新版本；
- 单实例运行，设置和位置按 Windows 用户保存在本地应用数据目录；
- 默认不开机自启，用户可在设置中主动开启。

这些默认决策由项目维护流程负责维护。只有明显改变用户体验、隐私权限或安全边界的选择需要再次询问用户。

## 4. 已确认但仍需实现时细化的规则

- 音乐从暂停或停止进入播放时按设置使用随机或固定循环动画；暂停确认后立即恢复用户选择的 Q 版小人或完整全身模式，不播放专用暂停动画。
- 音乐状态临时覆盖显示模式，但不修改用户的模式选择。
- 暂停后恢复播放时按用户的随机或固定规则重新选择音乐持续动画。
- 用户从菜单退出桌宠时播放一次“裂开晃动”；系统关机、注销或崩溃路径不等待该动画。
- 完整全身身体区域只在完整全身待机可见且没有一次性反应覆盖时接受点击。
- 一次性反应过期后不补播；同源通知短时间合并。
- 原神等受保护进程位于前台时，停用模拟输入、文件接收和普通临时置顶。
- 普通全屏应用前台时桌宠退到桌面层；受保护游戏独占全屏时可隐藏并降低帧率。
- 操作失败或超时只显示与失败原因对应的气泡文字，不播放“呜呜晃动”。
- 完整全身模式点击眼睛播放“心软软”，点击脚播放“糟了晃动”。
- 完整全身模式点击普通身体部位固定播放“十二周年·抱抱”；脸部播放“贴贴”，嘴部播放“啾啾”；完成头顶往返摸头后播放“天依游学记·国乐季 · 摸摸”。

## 6. 当前风险

1. 透明窗口已移除阻塞式 `DragMove` 并改为捕获鼠标后的手动移动；当前按虚拟桌面边界夹取，但跨 DPI 显示器仍需实测。
2. QQ/微信标题和应用图标仍依赖包身份、Windows 通知访问授权及来源应用产生 Toast；任务栏闪烁回退不依赖包身份，先显示 QQ / 微信来源；QQ 开启详情且原生托盘卡已展开时可从公开 UIA 补全昵称和未读数，卡片关闭或结构不兼容时保持来源提醒。现有未读消息不会生成新事件；若来源应用同时关闭 Windows 通知和任务栏闪烁，桌宠遵守不读取聊天私有数据的边界，无法保证检测。其他电脑的测试安装版首次安装仍需要一次 UAC 信任公开开发 CER；正式公开版需 Microsoft Store 或受信任生产签名，才能免去证书步骤。
3. 透明异形窗口的像素命中和点击穿透已持续验证；非桌面临时目录文件已通过真实 Shell 回收测试，Explorer 桌面全屏特例也有自动化覆盖，但外部 Explorer 的 OLE 拖动光标最终仍由拖动源参与反馈，Windows 可能叠加移动操作角标；资源管理器实际拖入的 400 ms 手感和不同系统主题下光标外观需要用户实测。
4. 新完整全身立绘和表情包画风不同；第二模型身体动作已改用无闪光的同本体原地播放，第三模型身体反应使用纯透明淡出/淡入，音乐等其它反应仍使用遮罩式过渡。后续新素材需按所属外观分别检查人物锚点、缩放与过渡策略。
5. 文件回收站主链路已经只用自动生成的临时文件做过真实验证；后续仍只能用临时项目测试，且任何失败都不得增加永久删除回退。
6. 当前网易云快捷键使用首轮默认组合；若用户在网易云中改过全局快捷键，需要在后续设置页同步修改，否则桌宠只能确认“输入已发送”，不能保证播放器响应。
7. 当前网易云版本没有注册 Windows 系统媒体会话，曲名依赖其主窗口标题兜底；如果网易云以后隐藏标题、改格式或启用不带标题的迷你模式，桌宠只能安全降级为“暂未读取到歌曲名称”。
8. 网易云独立音量已重新启用并会在每次操作时枚举所有活动输出设备及全部匹配会话；仍需用户在切换默认输出设备、蓝牙耳机和多会话播放场景下做手感验收，任何失败都不能退回系统主音量。
9. 设置窗口已按确认稿改为左侧导航紧凑控制台；四页已通过真实 WPF `PrintWindow` 截图检查，常规和音乐页在内容超高时仅右侧出现窄纵向滚动条。控制岛已在 50% 与 200% 实窗验证完整显示并限制宽度；125%/150% 系统 DPI 下的文字换行和间距仍需用户实际确认。
10. 会话解锁和电源恢复已通过隔离 QA 事件验证；为避免中断用户，本轮没有真的锁屏或让电脑睡眠，仍需后续在真实恢复路径做一次人工验收。
11. 原神联动的调度、普通权限枚举和真实 WPF 展示已隔离验证；为避免账号与反作弊风险，本轮没有启动原神，也没有在真实游戏前台/全屏中运行桌宠，最终兼容性仍需用户后续自愿观察。
12. 便携测试 EXE 没有商业代码签名，其他电脑可能显示 SmartScreen“未知发布者”；测试者应先核对随包 SHA-256。程序级清理不触碰 Windows 自身可能保留的下载、SmartScreen、安全扫描或系统事件记录。
13. 左右砖墙、底部头发触发面、当前帧反向和上下边缘悬浮岛换位已通过真实 WPF 截图及输入验证；跨 DPI、多显示器边界的贴边/越界门槛与拖出手感仍需人工验收。
14. 网易云退出后残留无窗口后台进程的误判已修复并有平台回归测试；真实“重新拉起→等待 2 秒→发送播放快捷键→有声确认”仍会改变用户音乐状态，因此最终链路留给用户主动点击验收。
