# 当前项目结构索引

更新时间：2026-09-14。本文记录 Stage 2 低风险源码整理、模块 A 素材迁移和模块 B 产物审计后的真实目录和职责。模块 B 已完成；`原素材/` 是本地构建输入，`assets/` 只保留运行时资源和正式加工产物。

## 根目录

| 路径 | 当前职责 |
|---|---|
| `global.json` | 固定 .NET SDK 10.0.400；SDK 只作为构建工具。 |
| `Directory.Build.props` | 全局 C#、Nullable、隐式 using、警告和 net48 兼容包设置。 |
| `LuoTianyiPet.sln` | 正式项目、测试项目和 AssetCompiler 的解决方案入口。 |
| `src/` | 四个正式项目。 |
| `tests/` | Core、Animation、Platform.Windows 三组自动化测试。 |
| `tools/` | 资产编译、诊断、维护、打包和 UI/动画制作工具。 |
| `assets/` | 运行时资源和已迁移的构建输入；`source/` 保存可追溯的原始构建输入副本。 |
| `候选素材_官方/` | 官方原始/候选/标注素材，源文件保留，等待用户手动删除。 |
| `config/` | 统一版本源、场景规则和动画来源等可追溯配置。 |
| `packaging/` | MSIX、外部位置身份包、旁加载和便携包的清单、安装器和清理脚本。 |
| `docs/` | 需求、安全、架构、路线图、日志、验证和本索引。 |
| `artifacts/` | 历史 worktree、发布物、QA 和中间产物；受保护，未经确认不清理。 |

## 受保护边界

- `assets/animations/runtime/`、`assets/manifests/`、`assets/audio/`、`assets/objects/`、`assets/cursors/` 和 `assets/ui/` 是运行时资源，不能因目录整理被删除或改名。
- `原素材/` 是动画编译和素材处理工具的唯一来源副本；本轮由 `assets/source/` 原样复制，不裁剪、不压缩。旧 `assets/source/` 已在迁移验证通过后清理。
- `候选素材_官方/` 原始素材保持原位置；后续素材迁移只能复制并记录来源，不得覆盖或删除源文件。
- `artifacts/` 含历史 worktree、QA、发布包和可能的用户数据/签名材料；本索引阶段只记录，不清理。
- 任何源码移动必须同步项目文件、测试引用、资源 Link、打包脚本和文档，并在移动后完成 net48 编译与测试。
